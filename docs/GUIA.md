# Guia del laboratorio de ramas.

Esta guía explica el proyecto del Laboratorio 02: una página web mínima
que usé para practicar ramas, merge y resolución de conflictos con Git.

## Se necesita
- Tener git instalado y configurado
- Visual studio code
- Una cuenta en Github

## Archivos del laboratorio

| Archivo | Para que sirve |
|----|----|
| index.html | La pagina con el titulo, el menu y el pie de pagina |
| estilos.css | El color del titulo |
| GUIA.MD | Descripcion del repositorio

## Como usarlo

###Clonar y abrir

1. Copiar la direccion desde el boton code
2. Clonar el repositorio
3. Abrir `index.html` en el navegador

```bash
git clone https://github.com/Joan322-cloud/lab02-ramas.git
cd lab02-ramas
code .
```


### ver el historial de ramas

Usa `git log --oneline --graph --all` para ver como se separan y se unen las ramas.

## Lo que practique en este laboratorio
- [x] Crear ramas con checkout -b
- [x] Hacer un merge fast-forward
- [x] Resolver un conflicto a mano
- [ ] Usar ramas en un proyecti eb equipo
